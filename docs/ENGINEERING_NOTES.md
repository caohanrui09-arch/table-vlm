# Engineering notes (2026-11-22)

This file records the reproducibility and portability work done after the
research pipeline was frozen. It does not change the model, training data,
evaluation protocol, or the sealed test150 results.

## Why

The original research snapshot depended on the author's machine:

- `table_vlm/demo.py` had absolute `D:/...` defaults;
- `start_demo.ps1` / `stop_demo.ps1` wrote to a fixed demo directory;
- `run_inference.ps1` relied on a sibling `.inference-deps`;
- the demo required a separate model-worker environment;
- there was no preflight for the base revision, adapter hash, CUDA, or port.

## What changed

### Portable paths and configuration

- `table_vlm/paths.py`: every default is relative to the project root; override
  with `TABLE_VLM_MODEL`, `TABLE_VLM_ADAPTER`, `TABLE_VLM_OUTPUT`,
  `TABLE_VLM_GPU_PYTHON`, or `TABLE_VLM_PYTHONPATH`.
- The default adapter is the bundled `artifacts/q1-adapter`; output goes to
  `demo-output/`.
- The worker no longer depends on `.inference-deps`. If an environment keeps
  packages out of tree (for example a separate `torchvision`), pass
  `--extra-pythonpath` or set `TABLE_VLM_PYTHONPATH`.

### Preflight and packaging

- `table_vlm/doctor.py` / `table-vlm-doctor`: Python, base metadata/weight size,
  pinned revision, Q1 adapter SHA256, output directory, torch/CUDA/torchvision/
  transformers/peft, and port.
- `--deep` verifies every file in the model receipt (including the 4.25GB
  weight); `--json` is machine-readable.
- `pyproject.toml` adds the `table-vlm-demo`, `table-vlm-infer`,
  `table-vlm-download`, `table-vlm-evaluate`, and `table-vlm-doctor` entry
  points.
- `scripts/package_release.py` builds a release zip plus a SHA256/size manifest
  and re-verifies every payload.

### Demo and worker

- `demo.py`: `--host`, `--timeout`, `--example`, `--skip-preflight`; validates
  the frozen base revision and adapter before inference; keeps the strict HTML
  check, sandboxed preview, CSP download, and failure records.
- `demo_infer.py`: `--device auto|cuda|cpu` and `--seed`. On CUDA the frozen
  settings are unchanged: min_pixels 65536, max_pixels 196608, newline prompt,
  BF16/SDPA, greedy, repetition_penalty 1.0, max_new_tokens 4096. CPU is only
  for slow plumbing checks.
- `examples/table.png` is synthetic, generated by `examples/make_example.py`.

### Launch scripts

- `start_demo.ps1` / `stop_demo.ps1`: parameterized paths, PID/start-time
  ownership record, no blind port killing.
- `run_inference.ps1`: no `.inference-deps` hard dependency.
- `scripts/setup_demo_windows.ps1`, `scripts/setup_demo_autodl.sh`,
  `scripts/run_demo_autodl.sh`, `scripts/run_demo.py`.

### Tests

- `tests/test_config.py`: path defaults/overrides and frozen demo parameters.
- `tests/test_doctor.py`: missing/truncated weight, wrong revision, adapter hash,
  output directory, port, missing interpreter.
- `tests/test_demo_service.py`: request directory, manifest, result JSON,
  preview/export, truncation/invalid HTML, adapter hash rejection, worker
  timeout, extra PYTHONPATH.
- Original `tests/test_demo.py` still passes.

## Verification

- Original snapshot: 236 files, all SHA256 match the transfer manifest.
- 22 selected offline tests pass.
- Full local discovery: 74 tests, 71 pass; 3 errors only because this offline
  shell lacks `Levenshtein` / `imagehash`, which `requirements-data.txt`
  installs.
- Real inference on RTX 4060 Laptop 8GB with the pinned base and Q1 adapter:
  76.1s total (51.5s generation), peak allocated 4.13GiB, valid HTML.
- Gradio API call: 78.7s; preview/raw HTML/download returned.
- `doctor --deep`: 11 model files verified, revision
  `89644892e4d85e24eaac8bacfd4f463576704203`, adapter SHA256 match.

## Limits

- The base 4.25GB weight is not in the repository; download it with the pinned
  manifest.
- Raw PubTabNet data, test images, and raw test predictions are not included.
- The AutoDL scripts were not executed on a real AutoDL instance; run `doctor`
  first on the target host.
- This work does not change or re-score the sealed test150.
