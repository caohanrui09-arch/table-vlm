# A 项目实验协议 v2：评分适配勘误

状态（2026-11-02，最终）：Q0/Q1/Q2开发实验与冻结test150三方法对照均完成。预先选定Q1，最终TEDS Q0=0.541862、Q1=0.688861、P0=0.746740。冻结设置未因test改变；保留Q2负结果，不再在本test上调参。评分仍为table-html-v2-data-bbox，历史勘误保留。完整证据见FINAL_REPORT.md。

## 要回答的问题

在相同 Qwen3-VL-2B、相同图像上限和训练曝光次数下，表格监督微调是否改善结构与内容识别？训练图像退化增强是否改善预先定义的低清晰度条件，是否损失干净表格效果？

## 三个主实验与一个对照

| 名称 | 变化 | 固定条件 |
|---|---|---|
| Q0 | 原始 Qwen3-VL-2B，不微调 | 固定权重 revision、提示、图像像素上限和解码 |
| Q1 | 真实表格 HTML 监督 LoRA | q/v 投影、rank=8、alpha=16，冻结视觉和投影层 |
| Q2 | 与 Q1 相同，仅替换部分训练图像为预设退化版本 | 样本 ID、顺序、标签和总曝光次数与 Q1 相同，不把 clean+aug 拼成双倍数据 |
| P0 | 原生 PaddleX PP-OCRv4-mobile + SLANet_plus CPU 流水线 | 官方预训练小模型，输入同一批裁剪表格，不使用正确单元格框或文字答案 |

P0 是轻量传统流水线基线，不等于 PaddleOCR 官方最佳配置。CPU 和 GPU 耗时分开报告，不能用两种硬件直接排速度名次。

## 正式数据协议

- 原始数据采用上游 train/val；不把公开无标注 test 填入假答案，也不拿模型输出当真值。
- 目标约 3,000 条独立训练表格，开发和最终测试各约 150 条；最终数量按完整论文分组和质量检查确定，再冻结清单和哈希。
- 按 PMC 论文 ID 分组；检查同文档与完全相同图片泄漏。若原始 split 存在论文交叉，先记录并决定隔离规则，不让代码默默换 split。
- 正式子集已复用ImageHash4.3.2检查跨划分pHash/dHash近重复候选，二者汉明距离<=4且宽高比差<=5%时隔离，当前未检出。该启发式不证明没有语义重复或预训练污染。
- 无法转换、损坏或超长的数据记录具体拒绝原因、数量和来源；阈值在跑模型前决定。不能通过删掉难题提高测试成绩。
- 开发集选择提示、超参数和失败处理；固定后才运行最终测试。当前 smoke 的 test 内容不进入人工检查页面。

## 首次训练配置

训练 seed=42，图像 max_pixels=196608、min_pixels=4096（显式与推理一致），序列 cutoff_len=4096、packing=false，batch=1，梯度累计=8，学习率 1e-4，epoch=2，BF16，gradient checkpointing。真实长度由 processor 检查，再核对 LlamaFactory 实际编码长度；禁止无记录地截断 HTML 标签。

先完成 8 步工程验证及 adapter 重载，再执行正式训练。seed=42 是主实验起点，不冒称多种子结果。若预算允许，另做预先登记的种子复验，并同样报告失败。

## 增强规则

按样本 ID 与 seed 确定 clean/blur/low_resolution/tilt，不改变标签。算法及参数范围写在 `data.py`，每张图保存实际 transform；不根据测试效果调整强度。被选中 clean 的图保持原字节。开发和测试在 Q1/Q2 之间必须指纹一致。

需要评价退化输入时，事先生成单独、固定的评测版本，与 clean 结果分别报告；不能事后只选有利退化，也不能将其放回训练。

## 评分与失败

- 主指标 TEDS，辅助 TEDS-S；同一份固定上游实现，两侧同样规范化 th/td 及无关展示属性。
- 附有效受支持 HTML 比例、错误类别、按表格复杂度分组结果。数字 token 按展平单元格序号匹配，仅作诊断，不称业务字段准确率。
- 空结果、缺预测、生成错误和超长截断保留在全量分母并计零。标注本身非法属于数据错误，应在冻结前发现，不能评分时悄悄剔除。
- 不用解析器补齐未闭合表格。展示用样式可以忽略，但结构嵌套和跨行/跨列属性必须合法。
- “控制标注扰动检查”与“真实模型预测”分开标记。前者验证指标是否识别错字/错结构，不是模型准确率或实验收益。
