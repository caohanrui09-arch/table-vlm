# Synthetic example

`table.png` is generated by `make_example.py` with Pillow and Arial. It contains
no PubTabNet image, paper content, or personal data. It exists only so the demo
has a working example immediately after cloning.

Regenerate:

```bash
python examples/make_example.py
```

The image is intentionally simple (5 columns, 5 rows) and is **not** an
evaluation sample or a quality benchmark.
